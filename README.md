# ChatGPT Themes

**Personalise your ChatGPT experience with custom chat backgrounds.**

ChatGPT Themes is a Firefox browser extension designed to let users customise the appearance of ChatGPT by applying personalised chat background themes.

Make your ChatGPT experience feel more personal with a look that suits your style.

---

## Features

- **Custom Chat Backgrounds** – Personalise the background of your ChatGPT interface.
- **Personalisation** – Give your ChatGPT experience a different visual appearance.
- **Firefox Support** – Built as an extension for Mozilla Firefox.
- **Lightweight Experience** – Designed to customise the interface without changing how ChatGPT works.

## Installation

### Option 1: Mozilla Firefox Add-ons

Once the extension is approved and publicly available:

1. Visit the [ChatGPT Themes page on Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/chatgpt-themes1/).
2. Click **Add to Firefox**.
3. Confirm the installation.
4. Open ChatGPT and try the extension.

*The add-on page may not be publicly available until Mozilla completes its review.*

### Option 2: Install from GitHub

You can also test the extension locally:

1. Visit the [GitHub repository](https://github.com/krit-gupta-dev/ChatGPT-Themes).
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file.
5. Open Firefox and visit `about:debugging`.
6. Select **This Firefox**.
7. Click **Load Temporary Add-on**.
8. Select the extension's `manifest.json` file.

The temporary installation may be removed when Firefox restarts.

## Usage

1. Open [ChatGPT](https://chatgpt.com/).
2. Open the ChatGPT Themes extension.
3. Use its available customisation options.
4. Apply your preferred appearance.
